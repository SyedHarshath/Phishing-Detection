What OPTIMUS does

OPTIMUS processes a submitted web address to estimate whether it is phishing or legitimate and returns a confidence score. The prediction request processes the URL text; the application code does not fetch the destination page for its prediction.

When and what the extension sends

The extension requires you to accept its data notice before scanning. After consent, it automatically sends the full URL for qualifying HTTP or HTTPS page navigations to https://optimus-eewm.onrender.com for prediction. A URL can include its scheme, domain, path, query parameters, and fragment. Any of those parts may contain personal information, private search terms, account identifiers, or secret values. Avoid scanning private pages or URLs containing information you do not want sent to the service.

Automatic scanning excludes these hostnames and their subdomains: google.com, google.co.in, bing.com, yahoo.com, duckduckgo.com, ecosia.org, search.brave.com, yandex.com, and baidu.com. A manual scan in the popup sends the HTTP or HTTPS URL displayed or entered there; the automatic-scan exclusions do not restrict manual scans.

The extension also checks the API health endpoint to display service and model status. It sends prediction requests to /predict. If you submit feedback on a prediction, the extension sends its prediction ID and the label you selected to /feedback.

Information stored and why it is used

After a successful prediction, the application stores the full submitted URL, timestamp, predicted class, confidence score, and model version in a SQLite database. The URL is used to provide the prediction. Stored predictions may also be considered during later, separately controlled model improvement.

If you submit feedback, the application stores the label you selected and feedback timestamp with the prediction. It also records feedback and review history, including the claimed label, review status, and reviewer, provenance, and reason details when a review is recorded. User feedback is an unverified claim; it is not automatically treated as a correct label or used for training. A reviewer must separately verify a label and record provenance before it may become eligible for a training batch under the project's safeguards.

The extension code contains no advertising or analytics integration. The application code does not specify collection of account profiles or payment details. Hosting or network systems may process technical request information needed to provide the service; the exact information in the live service logs has not been confirmed.

Hosting, access, and sharing

The configured API address is optimus-eewm.onrender.com, under Render's hosting domain. The API service and Render's hosting infrastructure process requests sent there to provide OPTIMUS. The project code does not show another URL-sharing destination. The operators have not confirmed the live service plan, region, storage arrangement, backups, infrastructure logging, provider access, or any other data processors for this deployment.

The prediction and feedback endpoints do not require a user account or login. People with access to the service environment or its SQLite database may be able to access stored records. Authorized feedback reviewers may inspect URLs associated with feedback to review labels. The separate prediction-history endpoint is disabled unless an operator configures a shared access token. If enabled, it omits URLs by default, but an authorized caller can explicitly request them. Whether that token is configured on the live service has not been confirmed.

The application does not encrypt its SQLite database itself. This statement does not establish whether the hosting provider encrypts storage. The live storage encryption settings and provider controls have not been verified. We do not know what request details may appear in hosting or application logs, who can access those logs, or how long they are retained.

Retention and deletion requests

The application currently has no automatic retention period and no user-facing deletion feature. It does not define an automatic schedule for deleting prediction or feedback records. Disabling the extension stops future scans and feedback requests from that browser profile, but it does not delete records already stored by the service.

You may request deletion by emailing either operator at the address listed above. Requests will be reviewed and handled manually. Where possible, include the prediction ID if you have it, rather than sending the sensitive URL again; the ID may help locate the associated record. Do not include a full URL unless an operator explains that it is needed to identify the record.

This is a manual request process, not an automated deletion feature. No completion timeframe is promised. The application does not confirm deletion from hosting logs or backups, and those systems' retention and deletion practices have not been verified. Until the operators confirm a deletion procedure and how it applies to copies, do not assume that a request removes every copy of information.

Withdrawing consent

You can decline consent or disable scanning in the extension popup. The extension stores the accepted consent version and acceptance time locally in the browser profile. Revoking consent removes those saved consent values and prevents later automatic scans, manual scans, and feedback requests from that profile until you consent again. It does not cancel a request already sent or remove information already stored by the service.

Prediction limitations

A prediction and confidence score are model estimates, not guarantees that a website is safe or harmful. Do not rely on OPTIMUS as the only basis for deciding whether to visit a website or enter information.
