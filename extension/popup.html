Before scanning

When enabled, OPTIMUS automatically sends the full URL for each qualifying HTTP or HTTPS page visit, including its path, query parameters, and fragment when present. It excludes these hostnames and their subdomains: google.com, google.co.in, bing.com, yahoo.com, duckduckgo.com, ecosia.org, search.brave.com, yandex.com, and baidu.com. A manual popup scan also sends the entered URL. The configured service stores each successful prediction with the URL, prediction, confidence, model version, and timestamps. An authorized reviewer may access a URL you report to check its label. The server has no automatic URL deletion schedule.

A model result is an estimate, not a guarantee that a page is safe.
